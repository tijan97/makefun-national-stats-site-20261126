NusaStats — Statistics of Indonesia, 2019–2024: population, economy, prices, jobs, welfare and regions in one offline site. Every figure is a published number from Statistics Indonesia (BPS), the World Bank, Bank Indonesia or the ministry named beside it: 281.6 million people, GDP of Rp 22,139 trillion growing 5.03%, inflation 1.57%, unemployment 4.91%, poverty 9.03% and a Human Development Index of 75.02. Eight linked sections, canvas charts drawn in the browser, a searchable and sortable province table, and no network requests at all.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Or serve the site for a look around first:

```sh
node serve.ts
```

then open http://localhost:8080.
